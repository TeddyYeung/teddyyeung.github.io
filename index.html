flutter_jailbreak_guard

Flutter plugin · Android (Kotlin) · iOS (Swift) · v0.2.1

Jailbreak and root detection with Swift Package Manager support. A drop-in replacement for flutter_jailbreak_detection_plus that uses the same detection engines and gives the same results.

  • Swift Package Manager and CocoaPods on iOS
  • Fail-closed: a missing result reports the device as unsafe
  • Android root checks run on a background task queue, off the main thread
  • Choice of iOS engine license: IOSSecuritySuite 1.9.x (BSD-2) or 2.x (EULA)
  • Dart unit tests, a Kotlin unit test, and integration tests

flutter_mute_plus

Flutter plugin · Android (Kotlin) · iOS (Swift)

Check or toggle the device ringer mode (normal, silent, vibrate). A maintained fork of flutter_mute, whose last release was in 2021 and no longer builds with current toolchains.

  • Builds on Android Gradle Plugin 8 and 9
  • Compiles on Xcode 16 and later
  • Swift Package Manager support, with CocoaPods kept
  • Fixes a hanging openNotificationPolicySettings() call and an SPM compile error in the upstream PR
  • Unit and integration tests; drop-in Dart API; 160/160 pub points
