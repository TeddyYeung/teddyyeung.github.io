flutter/packages · image_picker_ios

Official Flutter team repository · Objective-C, Swift Testing Merged · shipped in 0.8.13+10

Fixed a long-standing iOS bug (flutter/flutter#132154, open since 2023) where picking an image that UIImage cannot decode, such as AVIF, left the picker hanging or was treated as a successful save.

  • The operation now completes with the existing invalid_image error instead of continuing with a nil image
  • Added a regression test that checks no path is returned and the NSOperation finishes
  • Went through the full flutter/packages process: Google CLA, several upstream merge-conflict resolutions, and porting the test to the new Swift Testing suite
